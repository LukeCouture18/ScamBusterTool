# Director benchmark

The frozen scenario file describes external observations and faults, and imports no director logic.
The runner exercises each tree's real Main routes, real Wallet Investigator worker/engine, and real
Form Submitter worker. Public site/Finder transports and blockchain provider responses are deterministic
fixtures; this is not a live recall or browser-detection benchmark. Dynamic/login browsing actions are
supplied identically to both arms, since Main must not click through authentication. The v4 arm receives
an initial manual public investigation request; it is not given an invented provider-recovery feature.
Provider backoff is advanced by the harness without sleeping; round counts are simulated time, while
reported wall times measure the actual process. The four-pivot fixture describes work delegated within
Finder, not four decisions made by Main. Never interpret that result as a measured Finder quality gain.
All scenarios and limits are held identical. No scenario identifiers are available to Main. Results
contain measured counters; unmeasured telemetry is null rather than an estimate.
